# 🍕 Sistema Pizzaria Miguel

Sistema de gerenciamento de pedidos para pizzaria desenvolvido em **Java**.

## 📋 Funcionalidades

- Cadastro de dados do cliente
- Escolha de pizzas e sabores
- Escolha de bordas e adicionais
- Seleção de bebidas
- Cálculo automático do valor do pedido
- Escolha da forma de pagamento
- Geração do resumo completo do pedido

## 💻 Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Maven
- Git
- GitHub

## 🎯 Objetivo do projeto

Projeto desenvolvido com o objetivo de praticar conceitos de programação em Java e simular um sistema de atendimento e gerenciamento de pedidos de uma pizzaria.
