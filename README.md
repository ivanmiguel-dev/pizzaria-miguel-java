# 🍕 Sistema Pizzaria Miguel

Sistema de gerenciamento de pedidos para pizzaria desenvolvido em **Java**, criado como projeto prático durante meus estudos em **Análise e Desenvolvimento de Sistemas**.

O sistema simula o atendimento de uma pizzaria, permitindo cadastrar os dados do cliente, montar pizzas, adicionar bebidas, escolher a forma de pagamento e gerar automaticamente o resumo completo do pedido.

## 📋 Funcionalidades

- Cadastro de dados do cliente
- Escolha de pizzas e sabores
- Seleção de bordas
- Inclusão de adicionais
- Seleção de bebidas
- Cálculo automático do valor do pedido
- Escolha da forma de pagamento
- Geração do resumo completo do pedido
- Exibição do status do pedido

## 💻 Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Maven
- Git
- GitHub
